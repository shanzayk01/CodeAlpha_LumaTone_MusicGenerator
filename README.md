# LumaTone

LumaTone is a simple music-making app that creates original instrumental ideas in a few different moods.

## Music styles

- **Six-String Sprint** — quick, energetic guitar riffs
- **Royal Raga** — Indian classical-inspired melodic phrases with a steady drone
- **Sunroom Piano** — warm, calm piano-led music
- **Midnight Pulse** — upbeat electronic rhythm and synth melodies

## What you can do

Choose a style, adjust the length and energy, generate a new piece, listen to it in the browser, and download the MIDI file.

Every generation is slightly different, so the same settings can produce a fresh result each time.

## Project goal

The project demonstrates music generation from note patterns and MIDI sequences in a simple, easy-to-use app.
